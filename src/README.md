## Información general

**Nombre del proyecto:** Tetris Educativo con preguntas matemáticas  
**Tipo de proyecto:** Videojuego educativo 2D  
**Lenguaje principal:** Python  
**Librería gráfica:** Pygame   

Este proyecto consiste en el desarrollo de un videojuego tipo Tetris, el cual integra las mecánicas clásicas del juego con preguntas matemáticas por niveles, con el objetivo de reforzar el aprendizaje de operaciones básicas de una manera interactiva y dinámica.


## Objetivo del proyecto

Desarrollar un videojuego educativo que combine entretenimiento y aprendizaje, permitiendo al usuario practicar habilidades matemáticas mientras avanza en los niveles del juego.


### Objetivos específicos
- Implementar las reglas básicas del juego Tetris.
- Integrar un sistema de niveles progresivos.
- Incorporar preguntas matemáticas al completar niveles.
- Diseñar una interfaz gráfica intuitiva y sencilla.
- Fomentar el aprendizaje a través del juego.


## Descripción del funcionamiento

- El jugador controla piezas que caen desde la parte superior del tablero.
- Las piezas pueden moverse y rotarse mediante el teclado.
- Al completar cierto número de líneas, el jugador sube de nivel.
- Al cambiar de nivel, se presenta una pregunta matemática.
- Si la respuesta es correcta, el jugador continúa avanzando.
- Si la respuesta es incorrecta, se muestra una pantalla de error con opciones para reintentar o volver al menú principal.


## Controles del juego

- **Flecha izquierda:** Mover la pieza a la izquierda  
- **Flecha derecha:** Mover la pieza a la derecha  
- **Flecha abajo:** Acelerar la caída de la pieza  
- **Flecha arriba:** Rotar la pieza  
- **ESC:** Volver al menú principal

## Instalación y ejecución

Asegurarse de tener Python 3 instalado.

1. Instalar la librería Pygame ejecutando: pip install pygame
2. Clonar o descargar el repositorio del proyecto.
3. Ejecutar el archivo principal: python tetris.py
