# Tetris Educativo (Versión Flet)

Este proyecto es una reimplementación del clásico juego de Tetris, desarrollado originalmente para un proyecto académico y modernizado utilizando **Flet** para permitir soporte multiplataforma en Android y Windows.

## Características
* **Tecnología:** Desarrollado en Python utilizando el framework Flet.
* **Multiplataforma:** Ejecución nativa en Android y Windows.
* **Optimizado:** Adaptado para dispositivos móviles con controles táctiles.

## Tecnologías Utilizadas
* **Lenguaje:** Python
* **Framework:** Flet
* **Compilación:** Flutter SDK
